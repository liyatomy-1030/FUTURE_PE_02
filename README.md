# AI Content Marketing using UGC Ads

## 📋 Project Overview
Generate UGC-style ad scripts with authentic tone, create multiple hooks for the same product, write problem-solution-CTA based ad formats, and adapt content for different platforms while matching brand voice.

## 🛠️ Tools
- ChatGPT / Claude / Gemini
- Optional: Runway / Pika / CapCut for video ideas
- Google Docs / MS Word
- GitHub

## 🎓 Skills Gained
- AI-driven content marketing
- UGC ad scripting
- Ad psychology & hooks
- Prompt engineering for conversions
- Brand voice adaptation

## ✨ Key Features
✓ Generate UGC-style ad scripts (short-form, authentic tone)
✓ Create multiple hooks for the same product (scroll-stopping)
✓ Write problem-solution-CTA based ad formats
✓ Adapt content for different platforms (Instagram, Facebook, YouTube Shorts)
✓ Match tone to brand type (D2C, local business, SaaS, creator brand)
✓ Focus on conversion, not generic content

## 📦 Deliverable
A complete AI-generated UGC Ad Content Pack including multiple ad scripts, hooks, CTAs, and captions for a real product or business, created using structured prompts and documented with prompt logic and outputs in this public GitHub repository.

## 🚀 Getting Started
